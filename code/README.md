# ANN expriments

This directory contains the notebooks used to run the ANN experiments for the assignment. The notebooks are organized by the type of index used (e.g., IVF, HNSW, etc.) and contain the code used to run the experiments, as well as the results and analysis of those experiments.

To run all the notebooks, you can use the `run_all.sh` script, which will execute all the notebooks in the correct order.
